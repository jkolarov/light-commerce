The wordmark is set in **Spectral Regular** (© 2017 The Spectral Project Authors, SIL Open Font License 1.1, https://github.com/productiontype/Spectral) and converted to SVG paths, so the logo needs no font file. The OFL allows the font to be used for a logo; the outlines are artwork, not a copy of the font software. The mark (a leaf on a drying rack) was drawn from scratch.

The photos show real places and plants, not the fictional farm. Les Claies, Combe-Rousse and Montaurel are invented.
